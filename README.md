# Software Testing Guide

A comprehensive guide to software testing techniques, methodologies, and best practices. This repository contains both theoretical explanations and practical examples using Python.

## Repository Structure

- `theory/`: Contains markdown files explaining different testing concepts
- `examples/`: Contains Python code examples demonstrating various testing techniques
- `tools/`: Contains examples of testing tools and utilities

## Topics Covered

### Testing Types
- Black-box Testing
  - Equivalence Partitioning
  - Boundary Value Analysis
  - Decision Table Testing
- White-box Testing
  - Statement Coverage
  - Branch Coverage
  - Path Coverage
- Grey-box Testing
- Unit Testing
- Integration Testing
- System Testing
- Acceptance Testing

### Code Quality
- Cyclomatic Complexity
- Code Coverage
- Static Analysis

## Getting Started

1. Clone this repository
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Explore the theory and examples

## Requirements

- Python 3.8+
- pytest
- coverage
- radon
